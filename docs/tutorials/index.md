Start with the [guided quickstart](/getting-started/quickstart). It delivers a
local greeting fix with independent review, tests, bounded repair, integration
and cleanup. Keep its `bright-lights` city and `practice` repository.

The primary path through these tutorials continues that project using the
default Gas City pack and your existing provider:

1. [Cities and Rigs](/tutorials/01-cities-and-rigs) — inspect the city and register your own repositories in place.
2. [Agents](/tutorials/02-agents) — submit a reusable greeting API to the built-in workers.
3. [Sessions](/tutorials/03-sessions) — observe, stop and resume that persistent work.
4. [Communication](/tutorials/04-communication) — inspect independent review, test and integration evidence.
5. [Formulas](/tutorials/05-formulas) — apply the same delivery method to a client of the accepted API.
6. [Beads](/tutorials/06-beads) — inspect the real dependency and verify the combined result; choose independent parallel work when useful.
7. [Orders](/tutorials/07-orders) — run a mechanical check without a model, then choose publication or customization.

Each page states its starting point. Optional configuration exercises use a
separate `my-city` setup for readers who want to build custom agents and
workflows. The guided path uses the existing default throughout.

See [How Gas City Works](/getting-started/how-gas-city-works) for the six
primitives behind the experience.
