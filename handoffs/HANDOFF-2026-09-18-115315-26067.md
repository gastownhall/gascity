## Commits and decisions

### `3ebfb326085a2c038ea8a767a83cc1f7485f59db` — `fix(beads): carry bd's blocked status through the read model`

`mapBdStatus` collapsed bd's six statuses to three, and the collapse erased `blocked`: every read path rewrote it to `open`. The supervisor bead API therefore reported all of a city's blocked beads as open, so the dashboard counted finished-but-blocked work as needing a human.

The commit widens the Gas City status set instead of compensating in the frontend. `mapBdStatus` now returns `blocked`, which reaches every reader through the four decode sites that share it: `BdStore`, `DoltLite`, `NativeDolt`, and the bead-event payload. Review and testing still collapse to open because no consumer distinguishes them.

The commit keeps `blocked` in the open set rather than making it terminal. `beads.IsOpenStatus` reports membership in that set, `ListQuery.Matches` treats `Status: open` as the set, and ready work remains narrower because bd's ready semantics exclude blocked work.

### `44cd9655a09f0ccceb840229d190465db45c353b` — `fix(convoy): resolve child status across stores`

This commit has no body. It passes every available city and rig store to the existing convoy membership resolver. The resolver remains the single place that deduplicates tracked children and selects authoritative live status.
