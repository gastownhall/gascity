# Acceptance helpers

Use the real pinned `bd` for split/default factory fixtures. Its Go build
information is part of the existing forwarding trust boundary; a shell wrapper
cannot satisfy it. Keep the unwrapped binary under `NewEnv`'s isolated HOME.
Leaving that HOME restores the tool-home wrapper. Never forge an inventory,
vouch, build-information record or cache entry to admit instrumentation.

Recorder controls explicitly select the existing proxied/local single-store
shape and prove that storage assignment before counting. Keep every non-vacuity,
fork/ping, ownership, preservation and cleanup assertion. Ordinary no-selector
factory coverage uses the real binary separately; do not transfer a control's
performance claim to it. Preserve the legacy binary's original arguments.

Port-collision recovery still requires the exact rig's diagnostic proof, no
pre-existing store, no pinned endpoint and at most the existing one recovery.
Only the exact proxied/local control selector is equivalent to an unspecified
local automatic-port backend; other selectors remain ineligible.

Keep schema parity in both directions and the existing probe deadline. Remove
successful temporary databases; retain failed state with its diagnostic path.
Copy failed probes into Bazel undeclared outputs before its private namespace
is destroyed. Export relevant failure evidence before cleanup. A source/protocol fixture is
not native provider, consumer or full-factory qualification.
